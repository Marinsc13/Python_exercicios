# 📱 Atividades Flet 

Projeto desenvolvido em **Python utilizando o Flet**, com o objetivo de praticar a criação de interfaces gráficas e a interação com elementos de uma aplicação.

## 📚 Atividades realizadas

### 1. Tela em formato de celular

Foi criada uma tela com tamanho semelhante ao de um celular, utilizando:

- Largura de 400 pixels
- Altura de 700 pixels
- Fundo na cor rosa
- Conteúdo centralizado na tela
- Nome e subtítulo

### 2. Caixinha de informações

Foi criada uma caixa utilizando `ft.Container` para apresentar informações de uma pessoa.

Foram utilizados:

- `ft.Container`
- `width=300`
- `padding`
- `bgcolor`
- `border_radius`
- `ft.Row`
- `ft.Icon`
- `ft.Icons.EMAIL`
- `ft.Icons.PHONE`

A caixa apresenta:

- Nome
- Descrição
- E-mail com ícone
- Telefone com ícone

### 3. Campo de nome e aceitação dos termos

Foi criado um pequeno formulário de entrada contendo:

- Campo para digitar o nome
- Checkbox para aceitar os termos
- Botão "Entrar"
- Mensagem personalizada após o botão ser pressionado

Quando o usuário aceita os termos e clica em **Entrar**, o sistema apresenta uma mensagem utilizando o nome informado.

Exemplo:

> Obrigada, Mariana!

Caso os termos não sejam aceitos, o sistema informa que é necessário aceitá-los para entrar.

## 🛠️ Tecnologias utilizadas

- Python
- Flet

## 🎯 Objetivos

- Praticar Python com Flet
- Aprender a criar interfaces gráficas
- Trabalhar com containers e componentes
- Utilizar ícones e campos de entrada
- Trabalhar com botões e eventos
- Criar interações com o usuário
- Praticar alinhamento e organização de elementos na tela
